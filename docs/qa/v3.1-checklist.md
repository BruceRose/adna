## Other acceptance points

- **Logo**: crisp at 1x and 2x, light and dark, on the questionnaire, results, style pages,
  admin and client report; no layout shift (explicit size via CSS).
- **Consent**: heading and first two bullets visible without scrolling on a 390 x 844 phone;
  event-app bullet only with `?aid=`; `consent_version` stored; the purge only changes
  expired rows (unit test with fixed dates).
- **Style pages**: all nine render; unknown ids return 404; results pages never put the
  response id into a style link (checked in the browser).
- **Import**: the example imports with the expected styles and badges; the six deliberate
  errors each produce exactly their own error; a missing `NS6` column is a file-level error;
  re-importing skips 3 duplicates; undo removes exactly the batch (all in tests).
